# c)

Notam specificitatea = P(- | not B) cu S.

P(+) = P(B) * P(+|B) + P(not B) * P(+ | not B)
     = 0.01 * 0.95 + 0.99 * (1 - S)
     = 0.0095 + 0.99 * (1 - S)

## Calculăm S pentru P(B|+) = 0.5:
P(B|+) = P(+|B) * P(B) / P(+) = 0.5

0.0095 / (0.0095 + 0.99 * (1 - S)) = 0.5
0.0095 = 0.5 * (0.0095 + 0.99 * (1 - S))
0.0095 = 0.00475 + 0.495 * (1 - S)
0.00475 = 0.495 * (1 - S)
1 - S = 0.00475 / 0.495
1 - S = 0.00959596

S = 1 - 0.00959596
S = 0.990404
S = 99.04%
